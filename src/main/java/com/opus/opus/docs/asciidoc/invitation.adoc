== `POST`: 외부멘토 초대 링크 발급 (관리자)

관리자가 대회에 외부멘토를 초대하는 링크 토큰을 발급합니다. 토큰 원문은 발급 응답에서만 내려가고, 서버에는 해시만 저장합니다. 토큰은 발급 후 48시간 동안 유효합니다. 역할은 `ROLE_외부멘토`만 가능합니다. 이메일은 소문자로 바꿔 저장합니다. 같은 대회에 같은 이메일로 취소되지 않은 초대가 있으면 발급할 수 없습니다.
