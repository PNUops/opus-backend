== `POST`: 외부멘토 초대 링크 발급 (관리자)

관리자가 대회에 외부멘토를 초대하는 링크 토큰을 발급합니다. 토큰 원문은 발급 응답에서만 내려가고, 서버에는 해시만 저장합니다. 토큰은 발급 후 48시간 동안 유효합니다. 역할은 `ROLE_외부멘토`만 가능합니다. 이메일은 소문자로 바꿔 저장합니다. 같은 대회에 같은 이메일로 취소되지 않은 초대가 있으면 발급할 수 없습니다.

== `POST`: 외부멘토 초대 수락

로그인한 사용자가 초대를 수락합니다. 수락하면 계정에 `ROLE_외부멘토` 역할이 추가되고 해당 대회의 멤버로 등록됩니다. 초대 이후에 새로 가입한 계정이면 기본 역할 `ROLE_학생`은 제거됩니다. 역할이 바뀌므로 새 accessToken을 응답으로 내려주고, 프론트는 이 토큰으로 교체해야 합니다. 같은 계정으로 다시 호출하면 에러 없이 200을 반환합니다.

수락할 수 없는 경우는 아래 순서로 확인합니다.

- 취소된 초대: 409 `취소된 초대입니다.`
- 다른 계정이 이미 수락한 초대: 409 `이미 수락된 초대입니다.`
- 재발급으로 교체된 링크: 409 `새로 발급된 초대 링크가 있습니다.`
- 만료된 링크: 409 `만료된 초대 링크입니다.`
- 초대 이메일과 로그인 계정 이메일이 다름: 403 `초대받은 이메일과 로그인한 계정의 이메일이 다릅니다.`
- 직원 계정: 409 `직원 계정은 초대를 수락할 수 없습니다.`
