== 알림 타입 (NotificationType)

알림 응답의 `targetType` 값에 따라 알림 발생 시점과 `targetId`가 가리키는 대상이 달라집니다.

[cols="2,3,3,1"]
|===
| 값 | 발생 시점 | 수신 대상 | targetId

| `TEAM`
| 팀에 팀원이 추가됨
| 팀원 전원
| 팀 ID

| `TEAM_COMMENT`
| 팀에 새 댓글이 등록됨
| 댓글 작성자를 제외한 팀원
| 팀 ID

| `TEAM_AWARDS`
| 팀의 수상 내역이 등록됨
| 팀원 전원
| 팀 ID

| `SUBMISSION_COMPLETED`
| 제출물이 제출됨 (재제출, 지각 제출 포함, 파일 추가 및 삭제는 제외)
| 제출자를 제외한 팀원
| 제출물 ID

| `SUBMISSION_FEEDBACK`
| 지도교수 또는 외부멘토가 제출물에 피드백을 처음 작성함 (기존 피드백 수정은 제외)
| 팀원 전원
| 제출물 ID

| `ADVISOR_ASSIGNED`
| 팀에 교수가 담당으로 새로 배정됨 (스태프 일괄 배정, 담당 팀 수정 시 추가된 팀)
| 팀원 전원, 배정된 교수
| 팀 ID

| `ADVISOR_UNASSIGNED`
| 팀에서 교수 담당 배정이 해제됨 (담당 팀 수정 시 삭제된 팀, 스태프 배정 삭제 시 담당하던 모든 팀)
| 팀원 전원, 해제된 교수
| 팀 ID

| `MENTOR_ASSIGNED`
| 팀에 외부멘토가 담당으로 새로 배정됨 (스태프 일괄 배정, 담당 팀 수정 시 추가된 팀)
| 팀원 전원, 배정된 외부멘토
| 팀 ID

| `MENTOR_UNASSIGNED`
| 팀에서 외부멘토 담당 배정이 해제됨 (담당 팀 수정 시 삭제된 팀, 스태프 배정 삭제 시 담당하던 모든 팀)
| 팀원 전원, 해제된 외부멘토
| 팀 ID
|===

지도교수, 멘토 알림은 배정 상태가 실제로 바뀐 팀에 대해서만 생성됩니다. 이미 배정된 팀을 다시 추가하거나 배정되지 않은 팀을 삭제하는 경우에는 알림이 생성되지 않습니다. 교수와 외부멘토 역할을 모두 가진 회원은 지도교수 알림과 멘토 알림이 모두 생성됩니다.
