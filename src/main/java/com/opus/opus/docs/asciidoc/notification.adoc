== 알림 타입 (NotificationType)

알림 응답의 `targetType` 값에 따라 알림 발생 시점과 `targetId`가 가리키는 대상이 달라집니다.

[cols="2,3,3,1"]
|===
| 값 | 발생 시점 | 수신 대상 | targetId

| `TEAM`
| 팀에 팀원이 추가됨
| 팀원 전원
| 팀 ID

| `TEAM_COMMENT`
| 팀에 새 댓글이 등록됨
| 댓글 작성자를 제외한 팀원
| 팀 ID

| `TEAM_AWARDS`
| 팀의 수상 내역이 등록됨
| 팀원 전원
| 팀 ID

| `SUBMISSION_COMPLETED`
| 제출물이 제출됨 (재제출, 지각 제출 포함, 파일 추가 및 삭제는 제외)
| 제출자를 제외한 팀원
| 제출물 ID

| `SUBMISSION_FEEDBACK`
| 지도교수 또는 외부멘토가 제출물에 피드백을 처음 작성함 (기존 피드백 수정은 제외)
| 팀원 전원
| 제출물 ID
|===
